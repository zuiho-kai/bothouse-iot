# 会动的表盘：皮肤怎么做

表盘上的角色用一张立绘做出来：整张图铺在细网格上，头、发梢、呼吸都是平滑的变形，
所以动起来不露洞、不漂脸；眼睛和嘴是贴在原位的几块小贴片（闭眼、往上看、半张、张开）。
渲染用 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion) 的网格变形引擎（`server/bothouse_iot/static/vendor/coopanion/rig.js`，
v0.2.18 原样，许可见同目录 LICENSE）；驱动三种状态的是 `server/bothouse_iot/static/dial-figure.js`。

| 状态 | 网页 | 圆屏 |
|---|---|---|
| 待机 | 呼吸缩放 ±0.6%、头和发梢 ±2° 正弦加弹簧、2–5 秒随机眨眼 | 录好的 24 帧循环（含一次眨眼），12 帧/秒 |
| 思考中 | 歪头、眼神上移、头边三个气泡 | 24 帧循环 |
| 正在回答 | 嘴按这句语音的音量包络开合（闭 / 半张 / 张开三档），头轻点 | 一张底图，只刷嘴那一小块，按板子实际放音的音量换嘴 |

状态之间约 0.25 秒缓过去。浏览器不支持 WebGL 或皮肤加载失败时，退回原来的静态头像。

## 目录

```
skins/<角色>/<皮肤>/
  skin.json        尺寸、贴图、部件、骨架参数
  base.png         母图（原样，所以静止时和母图逐像素一致）
  eyes_closed.png  闭眼贴片        eyes_think.png  往上看贴片
  mouth_half.png   半张嘴贴片      mouth_open.png  张嘴贴片
  frames-240.bin   圆屏帧包（240 圆屏，spotpear 1.28）
  frames-360.bin   圆屏帧包（360 圆屏，Waveshare 1.85C）
```

配置里每块板写 `skins = "skins/<角色>"`、`skin = "<默认皮肤>"`。网页 `/dial?skin=<皮肤>` 临时换；
板子用默认皮肤的 `frames-<屏幕边长>.bin`，没有就还是静态头像。

`skin.json` 的 `rig`（坐标都是母图像素）：

- `neck`：头转动的支点（脖子）。
- `head`：`[cx, cy, rx, ry]` 头的椭圆，里面整块跟着头转，往外 `headFeather`（默认 0.3 倍）渐弱到不动。
- `hair`：`[[x0, y0, x1, y1, "L"|"R"], ...]` 两侧长发的范围，越往下、越靠外摆得越多，靠身体那侧不动；`hairAmp` 发梢最大位移（像素）。
- `bubble`：思考气泡从哪儿冒出来。

背景是纯色（橘是黑底）时变形完全看不出来；背景复杂的图，`head` 和 `hair` 别伸进背景太多。

## 给一个角色做一款皮肤

1. **母图**：方形，最好 1024×1024，角色居中、头在上半部分，纯色背景。
2. **差分**：闭眼、张嘴两张。要求和母图同构图同坐标，只改眼睛 / 嘴。两种做法：
   - 本机 Qwen-Image（ComfyUI）局部重画：把脸那块放大到 1024，眼睛 / 嘴画上遮罩，
     `python tools/skin/qwen_inpaint.py <脸部放大图> <遮罩> <输出> "<提示词>" 0.9`。
     赛璐璐风格效果好；闭眼如果画出两道线，再画一张「没有眼睛只有皮肤」的，用 `closed_band` 只取睫毛那一条。
   - 图像编辑模型（如 gpt-image 的 edits 接口）：把整张母图交给它，只说「闭上眼睛 / 张开嘴，别的一点不改」。
     油画棒这类质感风格用它，纸纹和笔触接得上。
   往上看不用出图：脚本把母图的虹膜往上挪几个像素、下沿补眼白。
3. **描述文件**：照 `tools/skin/ju-standard.json`（脸部放大重画）或 `tools/skin/ju-pastel.json`（整张编辑）写，
   填眼睛露出部分和虹膜的椭圆、嘴的范围、骨架参数。
4. **生成**：`python tools/skin/build_skin.py <描述文件> skins/<角色>/<皮肤>`。贴片自动羽化边、颜色对齐到母图；
   半张嘴是把张嘴压扁贴在抹平的皮肤上（抹平处补上旁边脸颊的纹理）。
5. **看效果**：`python tools/dial_demo.py --skin <皮肤>`（自带的是橘；别的角色加 `--config`），打开它打出的地址，
   三种状态轮流切。核静止帧：`python tools/dial_frames.py --url <表盘地址> --check --mother <母图>`，应是最大差 0。
6. **录圆屏帧**：`python tools/dial_frames.py --url "<表盘地址>&skin=<皮肤>" --size 360 --out skins/<角色>/<皮肤>/frames-360.bin`
   （240 的屏再录一份 `--size 240`）。要 playwright。

「油画棒」这类风格皮肤是**照参考图重画**，不是给标准版加滤镜（只加纸纹颗粒的版本看着还是原来的赛璐璐画）：

1. 找一张这种画法的参考图（橘用的是一张蜡笔涂鸦小人：抖动断笔的黑描线、看得见方向的蜡笔排线、
   大块简化的头发和花、几乎没有渐变、白纸底）。
2. 把标准版母图（内容）和参考图（画法）一起交给图像编辑模型，提示词写清参考图的画法逐项是什么、
   哪些细节要砍掉（耳坠、流苏、编发、书页金边之类），并要求构图、缩放和眼睛高度和标准版一样。
3. 把参考图和新母图缩到同一像素尺度并排，逐项比描线、笔触、简化程度、渐变高光；不像就按差的那几项再改一轮
   （在最接近的那张上小改，比每次从头画收敛快）。橘这款改了五轮。
4. 新母图上再按 2–6 步做。整张重画的闭眼图会顺手改刘海、纸色，描述文件加 `"closed_keep_hair": true`；
   眼睛下沿是描线的画风给每只眼加 `"fill": "keep"`。眼睛和嘴的坐标要按新母图重新量。

「涂鸦」皮肤是**参考图本身**：用户看中的那张蜡笔涂鸦小人（312 像素的视频帧）交给图像编辑模型，只要求高清重绘成同一张图
（构图、底色渐变、描线、笔触都不动，去掉帧里的鼠标箭头），不往标准版构图上靠，所以人在圆屏里比另两款小、带灰蓝到米色的渐变底。
母图出来是 1254 像素，先缩到 1024。描述文件 `tools/skin/ju-doodle.json`；闭眼图整张重画时挡眼的刘海线会挪位，
build_skin 之后再跑 `tools/skin/lash_closed.py` 重做闭眼贴片（眼睛那块换成母图肤色，只取闭眼图里的描线和头发）。
皮肤可在 `rig` 里写 `bubbleFill`、`bubbleEdge`（CSS 颜色、边框）给思考气泡配色：三款均用纸白填充和深色描边。

## 圆屏帧包格式

`tools/dial_frames.py` 写、固件 `main/display/rh_dial_anim.cc` 读，小端：

```
"RHA1" | u16 边长 | u8 帧率 | u8 套数
每套：u8 种类 | u16 帧数 | u16 x, y, w, h（只有嘴这套有）| 帧数 × (u32 长度 + JPEG)
种类：0 待机循环  1 思考循环  2 说话底图  3 嘴（闭、半张、张开）
```

JPEG 用 4:4:4、不降采样（240、360 都能被 8 整除，解出来正好是边长×边长）。设备服务在给板子的 `rh_dial` 消息里带
`"anim": "http://<服务>/xiaozhi/dial/<角色>.anim"`，板子加 `?size=<边长>` 下载到 PSRAM，解码任务一帧帧解到后台缓冲，
到点换上。板子的 `rh_dial_stats` 通知里有 `anim_fps`（实际换帧数）、`decode_ms`（每帧解码耗时）、`psram_free`。
